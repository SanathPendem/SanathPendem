> **Production-oriented AI address intelligence platform combining NLP normalization, semantic retrieval, ML classification, human-in-the-loop review, and automated retraining.**

- **Architecture & Tech**: NestJS • FastAPI • PostgreSQL • LightGBM • Python • TypeScript • Docker
- **Key Features**:
  - Automatically parses, normalizes, and standardizes raw address data.
  - Predicts confidence scores using machine learning classifiers.
  - Routes uncertain or low-confidence edge cases for human review.
  - Features continuous feedback loops for automated model retraining.
- 🔗 [Source Code](https://github.com/SanathPendem/AI-Assisted-Property-Address-Standardization-System)

  - Delivers precise, citation-backed legal analysis and answer synthesis via LLM prompts.

#### 5. 🌊 Ground Water Level Forecasting Engine
> **Hybrid PCA–DWT–LSTM predictive modeling system for regional water resource time-series forecasting.**

- **Architecture & Tech**: Python • PyTorch / TensorFlow • DWT • PCA • LSTM Networks • Pandas
- **Key Features**:
  - Filters high-frequency signal noise via Discrete Wavelet Transform (DWT).
  - Reduces feature dimensionality using Principal Component Analysis (PCA).
  - Captures long-term temporal dependencies via LSTM networks to forecast regional groundwater depth.
- 🔗 [Source Code](https://github.com/SanathPendem/Ground-water-level-forecasting)
